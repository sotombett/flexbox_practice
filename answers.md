1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство CSS, включающее Flexbox это display: flex (или display: inline-flex). После его применения элемент становится flex-контейнером, а его прямые дочерние элементы flex-элементами. Они выстраиваются вдоль главной оси (по умолчанию в ряд) и могут гибко изменять размеры.


2. В чем разница между justify-content и align-items? Приведите примеры использования каждого.

justify-content выравнивает flex-элементы вдоль главной оси, align-items вдоль поперечной. 
Пример: justify-content: center это центрирование по горизонтали при flex-direction: row; 
align-items: center это центрирование по вертикали.


3. Что делает свойство flex-direction и какие значения может принимать? Как оно влияет на основную ось?

flex-direction задаёт направление главной оси. Значения: row (по умолчанию), row-reverse, column, column-reverse. Оно определяет, как располагаются элементы: слева направо, справа налево, сверху вниз или снизу вверх.


4. Объясните значение трех свойств в сокращенной записи flex: 1. Что означают flex-grow, flex-shrink и flex-basis?

flex: 1 это сокращение для flex-grow: 1, flex-shrink: 1, flex-basis: 0%. flex-grow - коэффициент растяжения при свободном месте; flex-shrink - коэффициент сжатия при нехватке места; flex-basis это базовый размер элемента.


5. Как работает свойство flex-wrap и в каких случаях его следует использовать?

flex-wrap определяет, переносятся ли flex-элементы на новую строку. Значения: nowrap (по умолчанию), wrap, wrap-reverse. Оно используется, когда нужно сохранить размеры элементов и позволить перенос, а не сжатие.


6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?

align-items выравнивает элементы внутри одной линии по поперечной оси. align-content выравнивает сами линии (ряды) и работает только при flex-wrap: wrap и нескольких линиях.


7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?

order изменяет порядок отображения flex-элементов без изменения HTML. Может быть полезно для адаптивности: например, нужно переместить боковую панель вверх или вниз на мобильных устройствах.


8. Что такое "осевая линия" (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?

Главная ось (main axis) это ось, вдоль которой располагаются flex-элементы. её направление задаёт flex-direction. Поперечная ось (cross axis) перпендикулярна главной. При flex-direction: row главная ось горизонтальна, поперечная вертикальна, а при column наоборот.


9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.

Адаптивный макет без медиа-запросов можно сделать с помощью flex-wrap: wrap и гибких размеров. Например: контейнер display: flex; flex-wrap: wrap; gap: 1rem; элементы flex: 1 1 250px. При нехватке места элементы переносятся на новую строку.


10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?

gap задаёт отступы только между flex-элементами, не создавая лишних отступов по краям контейнера. Он не требует отрицательных margin, проще в использовании, читаемее и не влияет на внешние границы.
